# Medium Unlocker

## Chrome Extension
- Chrome extension
- open Medium through Freedium
- click LBM to open the story on Freedium

## Tampermonkey (Userscript)
- Install Tampermonkey extension
- Add new script with `medium-unlocker.user.js`
- Auto-redirects Medium stories to Freedium
- Click any Medium link to open in Freedium
